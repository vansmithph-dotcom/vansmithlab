# Switzerland: grid, typography, system

*The Swiss system as a way of making complexity manageable and almost invisible.*

## About this collection

The Swiss tradition is interesting not for its appearance but because it was the first to make a visual decision transmissible: a grid can be described, taught, checked, and contested. This route reads it as an infrastructural project.
