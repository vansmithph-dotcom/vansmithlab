# Design Language

*How visual systems become a language — and how to read them*

## What is design language

Design language is not a style or a set of techniques. It is a system of decisions: how form and function relate, how hierarchy is built, how visual elements address the viewer. This collection covers movements, principles and authors whose work formed a shared professional vocabulary.
