# Project Rules

## Core development principles
- Never duplicate code.
- Prefer reusable components over repeated markup.
- Keep CSS modular, clear, and maintainable.
- Ensure every page uses the same shared layout.

## Content and localization
- Every article and content entry must support both English and Russian.
- Keep localized content structured consistently.

## Accessibility and quality
- Every image must include meaningful alt text.
- Every page must include SEO metadata.
- Every page must include OpenGraph metadata.
- Every page must include Schema.org metadata.

## Architecture and maintainability
- Keep components small and focused on a single responsibility.
- Favor simple, composable structures over overly complex ones.
- Preserve consistency across the project for easier collaboration and maintenance.
