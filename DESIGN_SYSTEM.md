# VAN SMITH LAB Design System

## Brand values
- Quiet confidence
- Precision over excess
- Modern luxury
- Editorial clarity
- Cultural intelligence
- Intentional storytelling

## Design principles
- Minimal, calm, and refined
- Strong hierarchy with generous whitespace
- Dark, monochrome foundations with selective warmth
- Elegant restraint over decoration
- Functional beauty and clarity
- Consistency across every touchpoint

## Typography
- Primary font: Inter
- Tone: precise, contemporary, editorial
- Headings: medium to semibold, tight tracking, understated elegance
- Body text: clear, readable, calm rhythm
- Text scale should feel deliberate and premium

## Color palette
- Background: #0B0B0B
- Text: #F5F5F5
- Accent: #C8A96A
- Muted text: #B7B1A8
- Borders: rgba(255,255,255,0.12)
- Use accent sparingly for emphasis and interaction

## Spacing system
- Base unit: 8px
- Small: 8px
- Medium: 16px
- Large: 24px
- X Large: 32px
- XX Large: 48px
- Section spacing: 64px to 96px
- Keep rhythm consistent and generous

## Grid system
- Max content width: 1280px
- Page padding: 32px desktop, 24px mobile
- Use a clean, editorial grid with consistent vertical rhythm
- Favor simple alignment and strong structure over complexity

## Buttons
- Minimal, understated, and deliberate
- Thin borders and quiet interaction states
- No heavy fills or gradients
- Rounded corners should not exceed 10px
- Use accent color only for primary emphasis

## Cards
- Clean borders and restrained spacing
- No shadows
- Minimal visual noise
- Content-first structure
- Emphasize typography and hierarchy over decoration

## Forms
- Simple, quiet, and legible
- Neutral surfaces with clear labels
- Minimal field styling
- Focus states should be subtle and polished
- Avoid unnecessary visual clutter

## Navigation
- Sticky header
- Clear hierarchy and minimal ornament
- Links should feel calm, precise, and effortless
- Language switch placeholder can remain simple and understated
- Navigation should remain readable across screen sizes

## Animations
- Smooth and restrained
- Short transitions with subtle motion
- Prioritize clarity over spectacle
- Hover states should feel elegant and lightweight

## Icons
- Minimal, geometric, and understated
- Use simple line work and quiet visual weight
- Maintain consistency with the overall editorial tone

## Image style
- Editorial and cinematic when used
- Prefer restraint and atmosphere over excess
- Keep imagery intentional and high quality
- Avoid playful or overly decorative treatments

## Editorial style
- Calm, sophisticated, and cultural
- Strong use of whitespace and thoughtful pacing
- Type-led presentation where possible
- Prioritize clarity, taste, and composition

## Code style
- Keep frontend code clear and readable
- Prefer semantic structure and maintainable components
- Use consistent naming and minimal abstraction
- Favor clarity over cleverness

## Naming conventions
- Use lowercase, descriptive names
- Prefer kebab-case for files and CSS classes
- Use clear, meaningful component and section names
- Keep terminology aligned with the brand voice

## Accessibility rules
- Maintain strong contrast at all times
- Ensure keyboard navigation is clear and logical
- Use semantic HTML structure
- Support readable text sizing and responsive layouts
- Avoid relying on color alone for meaning

## Responsive breakpoints
- Mobile: < 768px
- Tablet: 768px–1023px
- Desktop: 1024px and above
- Layout should feel refined at every size without sacrificing clarity
