\# Source Policy

Version: 1.0



\## Purpose



This document defines how sources are collected, evaluated, verified and referenced throughout VAN SMITH LAB.



These rules apply to every knowledge object.



\---



\## General Principles



\- Every factual statement should be supported by one or more sources whenever possible.

\- Sources must be traceable.

\- Primary sources have priority.

\- The most reliable source always takes precedence.

\- Lack of reliable sources must be explicitly indicated.



\---



\## Source Priority



Priority order:



1\. Official organizations

2\. Primary documents

3\. Academic publications

4\. Museums and archives

5\. Standards and patents

6\. Professional industry publications

7\. Established media

8\. Community sources

9\. Anonymous sources

\## Source Metadata



Every stored source contains:



\- Title

\- Author

\- Publisher

\- Publication Date

\- URL or Identifier

\- Language

\- Source Type

\- Reliability Grade

\- Access Date



\---



\## Multiple Sources



Whenever possible:



\- Important facts should be confirmed by multiple independent sources.

\- Independent sources should not simply repeat the same original publication.



\---



\## Conflicting Sources



When reliable sources disagree:



\- do not select a preferred version without evidence;

\- document the disagreement;

\- identify supporting sources;

\- mark the statement accordingly.



\---



\## Missing Sources



If no reliable source exists:



\- the statement must be marked as unverified;

\- unsupported assumptions must not be presented as facts.



\---



\## Citation Rules



Every factual statement should be traceable to its source.



Sources should remain accessible whenever possible.



\---



\## Updating Sources



Sources may be replaced when:



\- newer editions become available;

\- official corrections are published;

\- stronger evidence is discovered.



Older references remain in version history.



\---



\## Source Removal



A source may be removed if:



\- it becomes unavailable;

\- it is officially retracted;

\- it is proven to contain false information.



Removal must be recorded in the change history.



\---



\## AI Usage



AI may assist in discovering and organizing sources.



AI is not considered a source.



All referenced information must originate from identifiable external sources.



\---



\## Copyright



Source attribution must comply with applicable copyright laws.



Original content must not be reproduced beyond permitted use.



References must always identify the original source.



\---



\## Transparency



Every knowledge object must clearly indicate:



\- number of sources;

\- reliability of sources;

\- verification status;

\- last verification date.



\---



\## Editorial Responsibility



Final responsibility for source selection belongs to VAN SMITH LAB.
