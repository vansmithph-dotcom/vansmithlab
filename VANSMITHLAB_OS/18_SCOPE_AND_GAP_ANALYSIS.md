# Scope and Gap Analysis

## What the earlier documentation already established well

- Knowledge-first rather than blog-first editorial logic.
- Verification state, confidence and sources as part of every publication.
- Object relationships, timeline, gallery and video as a graph.
- Russian master and English adaptation.
- AI support for research, drafting, translation, media and distribution.
- Cloudflare/GitHub-based low-overhead technical direction.

## Gaps now closed by VANSMITHLAB OS

| Gap | OS response |
| --- | --- |
| Markdown treated as the whole database | Defined durable D1 knowledge domains and ownership boundaries. |
| Paragraph-level rather than claim-level proof | Added claims, citations, source snapshots and contradictions. |
| Translation not tied to a version | Added Russian master revision, localization lineage and stale state. |
| Automation had no safe decision policy | Added AI roles, outcomes, idempotency, checkpoints and six escalation codes. |
| AI/editor role conflicted with automation goal | Claude can now autonomously approve only when objective gates pass. |
| Media lacked operational provenance path | Added media briefs, rights records, disclosure and accessibility release gates. |
| Personal author vs faceless encyclopedia unclear | Added institutional default and clearly attributed analytical essays. |
| UI described as pages, not reader journeys | Added compact IA, page contracts, trust surface and UX acceptance criteria. |
| Correction propagation was undefined | Added versioned correction/retraction and downstream rebuild rules. |
| Security, cost and resilience omitted | Added secret boundaries, rate limits, backups, monitoring and budget controls. |

## What is intentionally removed or deferred

- Do not launch with every listed content type. Start with encyclopedia entry, glossary, article/research, analysis, timeline and collection; add gallery/video after rights workflow works.
- Do not build a visual network graph first. Good links, search and filters prove the graph before a complex visualisation.
- Do not publish to all social networks automatically first. Activate one channel only after source-release reconciliation and correction flow work.
- Do not implement profiles, accounts, comments, marketplace or membership before the reference product earns repeat use.
- Do not let AI create facts, canonical taxonomy, policy or legal conclusions without documented evidence and governance.

## Open decisions that do not block Phase 1

- Exact brand name styling and final visual identity tokens.
- Initial supported additional locales after Russian/English.
- Source-snapshot retention period and licensing process per jurisdiction.
- Whether signed essays show “Ivan Melnik” or another formal byline style.
- First social channel to activate.

These decisions are deliberately isolated so the knowledge core can begin without premature branding or platform complexity.
