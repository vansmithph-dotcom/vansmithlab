# Playbook 03 — Approved Knowledge to Media

## Input

An approved object/content revision plus `templates/02_MEDIA_BRIEF.md`.

## Procedure

1. Define educational purpose and whether media is documentary, licensed, illustrative or reconstructed.
2. Validate rights/origin for supplied assets. If unclear, hold or replace automatically; escalate only for policy-defined risk.
3. Generate a Gemini task from the approved brief and only verified visual facts.
4. Store original, prompt/template hash, model/version, disclosure and derivative metadata.
5. Produce localized caption, alt text and, for video, transcript/subtitles/chapters.
6. Run visual, rights and accessibility validation.
7. Attach by media ID to the source release; never paste untracked files directly into a page.
