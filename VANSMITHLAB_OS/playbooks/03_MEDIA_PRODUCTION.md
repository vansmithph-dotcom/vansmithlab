# Playbook 03 — Approved Knowledge to Media

## Input

An approved object/content revision, the article's author-supplied media reference records and `templates/02_MEDIA_BRIEF.md`.

## Procedure

1. Import the author's reference URL, optional asset URL, creator/context, proposed placement, supported claim/example and suggested alt/caption into the media brief. Treat it as a proposal; the VANSMITHLAB editor owns the final selection.
2. Open the reference page and confirm that it depicts the claimed work or mechanism; record the source URL and retrieval date. A dead, generic or mismatched link is a failed handoff.
3. Define educational purpose and whether media is documentary, licensed, illustrative or reconstructed.
4. Validate rights/origin for supplied assets. If unclear, hold or replace automatically; escalate only for policy-defined risk. A URL never counts as permission.
5. Generate a Gemini task from the approved brief and only verified visual facts.
6. Store original, prompt/template hash, model/version, disclosure and derivative metadata.
7. Produce localized caption, alt text and, for video, transcript/subtitles/chapters.
8. Run visual, rights and accessibility validation.
9. The VANSMITHLAB editor selects the final asset, crop or replacement and records the decision. Attach the approved asset by media ID to the source release; never paste untracked files directly into a page.
