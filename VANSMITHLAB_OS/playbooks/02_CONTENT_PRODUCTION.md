# Playbook 02 — Object to Article, Analysis or Timeline

## Input

An `evidence_ready` knowledge object and `templates/01_CONTENT_BRIEF.md`.

## Procedure

1. Choose an allowed content type and confirm whether the voice is institutional or signed analysis.
2. Select existing claim IDs; identify missing evidence before drafting.
3. Draft Russian content from claims, citations and documented interpretation boundaries.
4. Attach frontmatter: IDs, type, source revision, state, locale, related objects, media IDs.
5. Run Claude editorial/fact-ledger review and ChatGPT structure/metadata review.
6. Validate every factual statement, citation marker, link, trust panel field, rights note and accessibility requirement.
7. Release Russian only after `AUTO_APPROVE` or user resolution of an allowed exception.
8. Trigger localization, build projections, search/graph update and distribution package.

## Analysis rule

A signed analysis must contain an explicit thesis, author/byline and marked interpretation. It may introduce an argument; it may not introduce uncited factual claims.
