# Delivery Roadmap

## Phase 0 — Restore and lock the foundation

- Restore the deleted Next.js root files from Git.
- Confirm Node, lint, build and local preview.
- Commit `VANSMITHLAB_OS` as the canonical system.
- Add environment boundaries and a minimal CI check.

**Exit:** clean, buildable repository and a documented source of truth.

## Phase 1 — Knowledge core

- Create D1 core migrations: objects, localizations, claims, sources, citations, relations, workflow/audit tables.
- Implement source/claim/rights validation.
- Seed 10–20 representative objects across disciplines and create the first glossary terms.

**Exit:** a verified object can exist, be revised, cited and linked.

## Phase 2 — Public Russian encyclopedia

- Build Home, object, glossary, article, analysis, timeline, collection and search pages.
- Implement TrustPanel, CitationDrawer, related objects, revision history and metadata.
- Apply UX/UI system and accessibility tests.

**Exit:** readers can browse a small but real Russian knowledge library.

## Phase 3 — Editorial and localization engine

- Implement brief → research → claim → editorial → release workflow.
- Connect Claude/ChatGPT role adapters and run logging.
- Add English adaptation, semantic validation, stale translation handling and locale routes.

**Exit:** an approved Russian publication can safely produce English without manual copying.

## Phase 4 — Media and visual intelligence

- Connect R2, rights records, media briefs, derivatives and AI disclosure.
- Add image/video components, captions, alt text, transcript and credits.
- Connect Gemini only through approved media briefs.

**Exit:** media is useful, rights-aware and accessible.

## Phase 5 — Autonomous operations and distribution

- Implement Weavy orchestration, retries, monitoring and the six escalation paths.
- Build search/graph/SEO projections and correction propagation.
- Activate one social channel at a time after end-to-end tests.

**Exit:** the system can produce, release, monitor and correct content autonomously.

## Later, not now

- Interactive graph visualisation.
- Accounts, saved collections and personalization.
- Paid products, membership and B2B tools.
- Broad social-network automation.

These begin only when the knowledge core, correction loop and stable publishing cadence prove value.
