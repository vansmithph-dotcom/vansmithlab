\# Page Templates

Version: 1.0



\## Purpose



This document defines the canonical page templates used throughout VAN SMITH LAB.



Every published page follows a standardized structure to ensure consistency, usability and maintainability.



Templates define presentation only.



Editorial content remains independent.



\---



\## Principles



Every page shall be:



\- Consistent

\- Modular

\- Accessible

\- Searchable

\- AI-friendly

\- Responsive



\---



\# Template Types



Supported templates:



\- Knowledge Object

\- Research

\- Editorial

\- Comparison

\- Guide

\- Reference

\- Glossary

\- Collection

\- Gallery

\- Timeline

\- Video



Each template inherits the common page structure.



\---



\# Common Page Structure



Every page follows this hierarchy.



Page



↓



Metadata



↓



Header



↓



Primary Content



↓



Related Content



↓



Sources



↓



Footer



\---



\# Header



The header contains:



\- Title

\- Subtitle (optional)

\- Summary

\- Cover Image

\- Categories

\- Tags

\- Publication Date

\- Updated Date



The header provides immediate context.



\---



\# Primary Navigation



The top navigation remains consistent across all pages.



Includes:



\- Logo

\- Main Navigation

\- Search

\- Language Switcher



\---



\# Breadcrumbs



Every page displays breadcrumbs.



Example:



Home



↓



Knowledge



↓



Brands



↓



Prada



Breadcrumbs are generated automatically.



\---



\# Main Content



The main content contains the canonical article.



Editorial structure is defined by the content itself.



Application code never modifies article order.



\---



\# Knowledge Sections



Knowledge pages may contain:



\- Overview

\- History

\- Key Facts

\- Products

\- Technologies

\- Timeline

\- References

\- External Resources



Sections appear only when content exists.



\---



\# Sidebar



The sidebar may include:



\- Object Metadata

\- Related Objects

\- Collections

\- Timeline

\- Quick Facts

\- AI Tools



Sidebar modules remain independent.



\---



\# Related Content



Automatically generated.



May include:



\- Related Objects

\- Similar Objects

\- Parent Objects

\- Child Objects

\- Collections



Powered by the Knowledge Graph.



\---



\# Sources



Every page displays:



\- Verified Sources

\- Source Type

\- Publication Date



Sources remain separated from editorial content.



\---



\# Footer



Contains:



\- Copyright

\- License

\- Last Updated

\- Version

\- Navigation

\- Feedback
