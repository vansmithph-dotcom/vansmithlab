\# Repository Structure

Version: 1.0



\## Purpose



This document defines the repository structure of VAN SMITH LAB.



The repository is organized to separate source code, knowledge content, media assets, documentation and configuration.



\---



\## Principles



\- One repository

\- Clear separation of responsibilities

\- Predictable structure

\- Scalable organization

\- Version controlled



\---



\## Root Structure



/

├── docs/

├── architecture/

├── src/

├── content/

├── public/

├── assets/

├── scripts/

├── config/

├── data/

├── search/

├── ai/

├── tests/

├── .github/

└── package.json

\## src/



Application source code.



Suggested structure:



src/

├── components/

├── layouts/

├── pages/

├── lib/

├── services/

├── styles/

├── utils/



\---



\## content/



Knowledge library.



Suggested structure:



content/

├── knowledge/

├── research/

├── collections/

├── timelines/

├── galleries/

├── videos/



Content is stored as structured files.

\- workflows

\- issue templates

\---



\## Naming Rules



Directory names:



\- lowercase

\- descriptive

\- no spaces



File names:



\- lowercase

\- kebab-case



\---



\## Version Control



Everything required to rebuild the project must exist inside the repository except secrets.



Generated files may be excluded when reproducible.



\---



\## Repository Goal



The repository provides a clean, scalable and maintainable structure for long-term development of VAN SMITH LAB.
