\## Validation



Every workflow validates:



\- Required Fields

\- Metadata

\- Relationships

\- Sources

\- Object Status



Validation failures stop the workflow.



\---



\## Version Control



Each completed workflow records:



\- Workflow Name

\- Date

\- Object ID

\- Version

\- Result



\---



\## Error Handling



Workflow errors:



\- are logged;

\- do not overwrite published data;

\- may be resumed after correction.



\---



\## Workflow Independence



Each workflow has:



\- defined input;

\- defined output;

\- defined validation.



Workflows may be executed independently when appropriate.



\---



\## Consistency



All workflows comply with:



\- Manifest

\- Editorial Policy

\- Source Policy

\- Verification Policy

\- Knowledge Model



Every published knowledge object follows one or more of these standardized workflows.
